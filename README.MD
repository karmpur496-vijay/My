# 👷 LabourPro Master
A modern, open-source payroll and attendance system for labor management.

## Features
- 📊 Real-time Dashboard with attendance graphs.
- 📅 Dynamic Attendance Sheet (Auto-Sunday detection).
- 💰 Advance & Overtime (OT) tracking.
- 🖨️ Professional A4 Salary Slips and CSV Export.
- 🔐 Password Protected Admin Access.

## Tech Stack
- HTML5, CSS3 (Modern Flexbox/Grid)
- Vanilla JavaScript (No libraries needed)
- LocalStorage for Data Persistence
